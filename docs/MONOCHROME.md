# 单色图标与 Dock

本分支保留用户布局、壁纸、首页顺序和启动开关，更新应用图标呈现。

- 当前可启动应用均有独立单色标识：哔哩哔哩、云视听极光、银河奇异果、夸克网盘、优酷、芒果 TV、Moonlight、Emby、小米投屏、小米原桌面、电视设置、通知中心、电视管家。
- 品牌标识为开源素材或本地绘制的识别性简化图形，不声明是从所有 APK 提取的官方单色资源。来源见 assets/icons/SOURCES.json。
- 未覆盖的新应用通过 PackageManager 读取 APK 图标，转换为保留明暗细节的灰度图；不直接把整张不透明图染白。缓存按包名及更新时间区分，限 32 张 128×128 位图。
- Dock 使用统一圆角底板、暖白图形、选中描边与轻微放大；未选中应用保持可辨认。列表与全部应用页面共用图标映射。
- 不新增联网、图标下载或常驻动画，不改变自启动逻辑。

## 部署

CI 完成构建、Java 测试及 lint 后，下载 APK 并在本机通过 apksigner 使用固定 PKCS12 签名。私钥不能提交仓库或放进 CI 产物。

首次从临时 CI 签名迁移时已保存旧 APK 与完整 SharedPreferences，并以新应用自身 UID 恢复后逐字节比较。Android 9 的 tar 会尝试恢复旧 UID，故不可直接将 tar 的提取退出码作为数据是否恢复的唯一判断；用 run-as 逐文件写入并比较内容。后续同签名更新使用 adb install -r，保留数据。

## 验证边界

已检查真实电视首页和全部应用滚动列表，确认可启动项目图标映射。原厂默认桌面未改；开机与唤醒选项仍保持用户原值。图标适配不代表完成每个第三方 App 的播放或登录测试。
